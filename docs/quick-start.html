Wicket quick start

Connect Claude to a customer's Business Central, from Windows or a Mac. Nothing to install besides Claude: Claude Code or the Claude desktop app. The first connection goes to a sandbox and is read-only.

Business Central

With delegated admin access (GDAP) you do this yourself. Otherwise the customer's admin does it: send it with the button below.

  1. A sandbox

    Use an existing sandbox, or create one in the customer's Business Central admin center (businesscentral.dynamics.com/<customer domain>/admin), for example as a copy of production.

  2. Install Wicket and switch it on

    Open the sandbox in the browser. Download Wicket from the Releases page, unzip it, and upload the .app in Extension Management → Upload Extension.

    Then search Wicket Setup and choose the preset Simple Read-Only: every table becomes readable and nothing writable.

  3. Permission

    As a delegated admin you already hold what your partner licence configuration gives you, which Wicket accepts: nothing to do. For anyone else, open Users and add the permission set Wicket Data - Read to their user.

Send this to the customer's admin

Copies the three steps as a short email. Fill in the sandbox and company if you know them.

or open it in your mail app

You, in Claude

On Windows or an Apple-silicon Mac, in Claude Code or the Claude desktop app. Both share one setup: install both if you like.

Claude Code

  1. Install the plugin

    /plugin marketplace add davesmith7403/wicket
    /plugin install wicket@wicket

    Then run /reload-plugins, or restart Claude Code. On its first start Wicket downloads its server for your computer, once.

  2. Connect

    /wicket:setup

    Choose browser sign-in and paste the sandbox's address from your browser's address bar. Sign in with your own work account and pick the company. No GUIDs to look up.

    No browser on this machine (over SSH, say)? Choose device code instead.

  3. Ask

    /wicket:orient

    Then ask in plain words. What to ask below has examples to start from.

Claude desktop app

  1. Install the extension

    Download wicket-<version>.mcpb from the plugin's latest release and open it: the desktop app shows Wicket and installs it with one click.

    On its first start Wicket downloads its server for your computer, once.

  2. Connect

    Set up Wicket

    Say it in a new chat. Choose browser sign-in and paste the sandbox's address from your browser's address bar. Sign in with your own work account and pick the company. No GUIDs to look up.

  3. Ask

    Ask in plain words; Claude finds its bearings in Business Central on the first question. What to ask below has examples to start from.

    Dashboards and reports stay live here: while you have one open, it reads Business Central again.

What to ask

Ask for the result you want, and Claude picks the form: an answer, a list, a file, a dashboard, a report or a link. Tried on Business Central's standard demo data. Claude Code saves a file to a folder on your computer; the desktop app gives it to you as a download.

A quick answer

How many sales orders are open, and what are they worth in total?

A list

List the customers with overdue invoices: amount overdue, days late and salesperson.

An Excel file

Export all items with their unit cost, vendor and stock per location to an Excel file.

A dashboard

Build a dashboard of the last 12 months' sales: revenue by month, top customers and top items.

A written report

Write a one-page receivables summary for the finance meeting: what's overdue, who owes most, and what was paid this month.

A link to the record

Open the customer card of the customer with the largest overdue amount.

Beyond the APIs

Wicket reads any table Business Central has, including ledgers that no API page or query exposes. These two come from such tables (the value entries, and the detailed customer ledger), as do the overdue list and the receivables report above.

Gross margin per item

Show the gross margin per item for the last 12 months: sales, cost of goods sold and margin %.

How customers pay

How many days late, on average, does each customer pay their invoices? Rank them, worst first.

If something goes wrong

Wicket's tools don't appear
The first start downloads Wicket's server. Without network access, or behind a proxy (set HTTPS_PROXY), it can't; once that's fixed, run /mcp, choose wicket, then Reconnect. In the desktop app, open Settings → Extensions and switch Wicket off and on again.
"Wicket isn't installed in that environment"
Step 2 on the left was done in another environment, or setup picked another one. Run /wicket:setup again (in the desktop app, say “Set up Wicket”) and choose the sandbox where Wicket is installed.
"Signed in, but there is no Wicket permission set"
Step 3 on the left: the user needs Wicket Data - Read.
Signed in, but nothing can be read
The preset was applied in another company, or not yet. Wicket Setup holds one row per company: apply Simple Read-Only in the company you picked.
Blocked from the environment as a delegated admin
The customer's global admin has turned partner access off. They turn it on for your partner tenant under Partner access on the environment in the Business Central admin center.
The customer's sign-in policy blocks the sign-in
Some tenants don't allow Wicket's default sign-in app. In setup choose My own app registration; the customer's Entra admin registers one (guide, chapter 34).

Want more?
