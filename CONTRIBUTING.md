# Contributing to Wicket

Contributions are welcome: bug reports, fixes, new named actions, documentation.

This repository holds the Business Central extensions. The MCP server, the plugin and the usage
skill live in [davesmith7403/wicket](https://github.com/davesmith7403/wicket); changes to those go there.

## Before you start

- For anything beyond a small fix, open an issue first so the approach can be agreed before you
  write the code.
- Wicket keeps a wire contract with its callers. Read [docs/versioning.md](docs/versioning.md):
  additive changes are fine within `v1.0`; anything that removes, renames or changes the meaning of
  an operation or field needs a new URL major version.

## Layout

| Folder | What it is |
|---|---|
| `app/` | The core extension (System Application only, objects 94100–94199) |
| `actions/` | The optional Base-App companion with the posting wrappers (94200–94249) |
| `test/`, `actions-test/` | AL test apps for the core and the companion |
| `docs/` | Product Guide, setup, versioning policy and smoke-test recipes |

## Making a change

- **AL:** compile each app from its own folder (see the README). Add or update tests in `test/` or
  `actions-test/` for every behaviour change. A new operation touches the dispatcher, the
  authorizer, the capabilities manifest and the endpoint page's bound action — and a matching tool
  and skill section in the [plugin repository](https://github.com/davesmith7403/wicket).
- **Product Guide:** edit `docs/Wicket-Product-Guide.md`; the HTML and PDF are generated by `docs/build/`.

Keep pull requests focused on one change, and explain *why* in the description.
